## 業務フロー（Mermaid）

以下は顧客向け主要ユースケースの業務フローです。

```mermaid
flowchart TD
  subgraph A[会員登録・ログイン]
    A1[会員登録フォーム入力\n(メール・パスワード)] --> A2{入力チェック/強度}
    A2 -- OK --> A3[登録完了\n(確認メール案内)]
    A2 -- NG --> A1
    A3 --> A4[ログインフォーム]
    A4 --> A5{認証}
    A5 -- OK --> A6[ログイン状態]
    A5 -- NG --> A4
  end

  subgraph B[上映スケジュール閲覧]
    B1[映画一覧] --> B2[作品詳細]
    B2 --> B3[上映回一覧\n(余裕あり/残席わずか/完売)]
    B3 -->|空席あり| B4[上映回詳細\n(空席状況)]
  end

  subgraph C[座席選択〜予約]
    C1[座席表UI\n(最大5席選択)] --> C2[仮予約開始\n(2分カウントダウン)]
    C2 --> C3[予約内容確認\n(作品/時間/座席/料金)]
    C3 --> C4[決済(モック)\n即時確定]
    C4 --> C5[予約確定\n完了画面]
    C5 --> D1
  end

  subgraph D[予約履歴/キャンセル]
    D1[予約履歴一覧] --> D2[予約詳細]
    D2 --> D3{キャンセル期限内?}
    D3 -- Yes --> D4[注意事項表示\n最終確認]
    D4 --> D5[キャンセル実行\n返金処理(モック)]
    D5 --> D6[キャンセル完了\nメールプレビュー]
    D3 -- No --> D7[期限超過\nキャンセル不可案内]
  end

  A6 --> B1
  B4 --> C1
```

### 予約フロー詳細（シーケンス）

```mermaid
sequenceDiagram
  actor User as ユーザー
  participant App as フロントエンド
  participant Store as モックストア(LocalStorage)

  User->>App: 上映回を選択
  App-->>User: 空席状況を表示(余裕/わずか/完売)
  User->>App: 座席表から座席を選択(最大5席)
  App->>App: 仮予約タイマー開始(2分)
  App-->>User: 残り時間を表示
  User->>App: 確認へ進む
  App-->>User: 作品/時間/座席/料金の確認表示
  User->>App: 決済(モック)実行
  App->>Store: 予約レコード保存
  Store-->>App: 保存成功
  App-->>User: 予約完了画面表示
```

### キャンセルフロー詳細（シーケンス）

```mermaid
sequenceDiagram
  actor User as ユーザー
  participant App as フロントエンド
  participant Store as モックストア(LocalStorage)

  User->>App: 予約履歴を開く
  App->>Store: 予約一覧取得(ログイン中ユーザー)
  Store-->>App: 予約一覧
  App-->>User: 予約一覧表示
  User->>App: 対象予約を選択
  App-->>User: 予約詳細/キャンセル規定表示
  User->>App: キャンセルをクリック
  App->>App: 期限判定(キャンセル可否)
  App-->>User: 最終確認ダイアログ(対象/金額/返金注意)
  User->>App: 実行を確定
  App->>Store: 予約状態=キャンセルに更新
  Store-->>App: 更新成功
  App-->>User: キャンセル完了/メールプレビュー
```

## バックエンド処理（概念モック・Mermaid）

```mermaid
sequenceDiagram
  actor User as 顧客
  participant FE as フロントエンド
  participant API as APIサーバ
  participant Pay as 決済ゲートウェイ
  participant Mail as メール送信
  participant DB as データストア

  rect rgb(245,245,245)
    Note over FE,API: 1) 上映・空席取得
    User->>FE: 上映回を閲覧
    FE->>API: GET /movies, GET /showtimes
    API->>DB: クエリ(作品/上映/残席)
    DB-->>API: データ
    API-->>FE: 一覧/残席
  end

  rect rgb(245,245,245)
    Note over FE,API: 2) 座席ホールド(仮予約)
    User->>FE: 座席選択
    FE->>API: POST /holds {showtimeId, seats}
    API->>DB: 座席の状態=held(期限付)に更新
    DB-->>API: OK(holdId, expiresAt)
    API-->>FE: holdId, expiresAt
  end

  rect rgb(245,245,245)
    Note over FE,API: 3) 予約確定(決済)
    FE->>API: POST /checkout {holdId}
    API->>Pay: 課金オーソリ/キャプチャ
    Pay-->>API: 決済成功
    API->>DB: reservation作成/座席=reserved
    API->>Mail: 予約確定メール送信
    Mail-->>API: 送信OK
    API-->>FE: 予約ID/サマリ
  end

  rect rgb(245,245,245)
    Note over FE,API: 4) 予約履歴/キャンセル
    FE->>API: GET /me/reservations
    API->>DB: ユーザー予約一覧
    DB-->>API: リスト
    API-->>FE: 予約履歴

    FE->>API: POST /reservations/{id}/cancel
    API->>DB: キャンセル期限/ポリシー検証
    DB-->>API: OK/NG
    alt 期限内
      API->>Pay: 返金(全額/一部)
      Pay-->>API: 返金結果
      API->>DB: 予約=キャンセル/返金記録
      API->>Mail: キャンセル完了メール
      Mail-->>API: 送信OK
      API-->>FE: 完了
    else 期限外
      API-->>FE: エラー(期限超過)
    end
  end
```

### 役割の切り分け

```mermaid
flowchart LR
  C[顧客向けUI] -->|予約/キャンセル操作| API

  API --> DB[(データストア)]
  API --> Pay[決済]
  API --> Mail[通知]
```
