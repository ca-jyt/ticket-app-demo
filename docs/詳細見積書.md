# 詳細見積書（詳細設計・実装・単体テスト）

## 概要
映画館チケット予約システムの詳細設計、実装、単体テストに関する工数見積もりです。
フロントエンドは画面（UI）ごと、バックエンドはAPI単位で見積もりを行います。

---

## 見積もり前提条件

### 技術スタック
- **フロントエンド**: Next.js 14 (App Router), React, TypeScript, Tailwind CSS
- **バックエンド**: Next.js Server Actions / API Routes, Prisma ORM
- **データベース**: PostgreSQL
- **外部連携**: Stripe決済, SendGridメール送信
- **認証**: NextAuth.js

### 開発体制
- **フロントエンド開発者**: 1名（中級レベル）
- **バックエンド開発者**: 1名（中級レベル）
- **テスト担当者**: 1名（初級レベル）

### 工数算出基準
- **Low複雑度**: 0.5-1.0人日
- **Medium複雑度**: 1.5-3.0人日  
- **High複雑度**: 3.5-6.0人日
- **リスクバッファ**: 20-30%（新規技術・外部連携・複雑な業務ロジック）

## 5. 前提条件・制約事項

### 5.1 技術的前提
- Next.js 14 App Router使用
- TypeScript完全対応
- レスポンシブデザイン対応
- アクセシビリティ基本対応

### 5.2 業務的前提
- 座席選択は最大5席まで
- 仮予約は2分で失効
- キャンセル期限は上映開始24時間前
- 管理者は1名想定

### 5.3 品質前提
- 単体テストカバレッジ80%以上
- コードレビュー実施
- セキュリティチェック実施

---

## 6. リスク要因

### 6.1 技術リスク
- **外部API仕様変更**: Stripe決済API、SendGridメールAPI
- **パフォーマンス**: 座席選択時の同時アクセス
- **セキュリティ**: 決済情報の取り扱い

### 6.2 業務リスク
- **要件変更**: キャンセルポリシー、座席管理ルール
- **データ整合性**: 在庫管理、予約状態管理
- **運用**: 管理者操作の監査、エラー対応

### 6.3 対策
- 外部API仕様の事前確認
- プロトタイプでの早期検証
- 段階的なリリース計画
